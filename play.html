How to play

The server is not open to the public yet. Myths-V-Souls is in development and testing. The game download and server address will be posted here when it opens.

When the server opens

  1. Download the game client from this page and unpack it to a folder of your choice.
  2. Run the client and create an account on the login screen.
  3. Create a character. Pick one of eight classes - see the Classes page.
  4. Start in the Starter Village. Speak to the Village Guide; the quests lead you from there.

Handy keys

I

Your bag.

H

B

Keep health and mana potions on your belt; the Starter Village shop beside the safe zone sells both. Check an item's class, level and gender before equipping it.
